# UniSnap

UniSnap 是一套以 macOS 為目前主要目標的螢幕截圖、長截圖、圖片編輯與螢幕錄影工具。版本：**V 1.0**。

本專案使用 Tauri 建立桌面應用程式，前端採 React + TypeScript，原生功能採 Rust，並整合 macOS ScreenCaptureKit、xcap、OpenH264 與 AAC 音訊處理。

## 主要功能

- 矩形截圖、全螢幕截圖、工作區截圖。
- 多螢幕選擇：從功能列的螢幕選單選擇目標螢幕。
- 長截圖：先框選單一可捲動內容區，再自動捲動、擷取與拼接。
- 圖片編輯：裁切、擴增四周空白、畫筆、螢光筆、箭頭、直線、矩形、圓形、馬賽克與文字標註。
- 開啟舊檔：載入 PNG、JPG/JPEG 圖片後，在 UniSnap 內編輯並另存。
- 螢幕錄影：框選錄影區域，輸出 MP4；可選 FPS、麥克風與系統聲音。
- 錄影期間提供浮動控制列，可停止並完成存檔。
- PNG 與 JPG 另存新檔；JPG 可在設定調整壓縮品質。
- 剪貼簿複製與全域快捷鍵設定。
- 日間／夜間介面模式。

## 使用方式

### 1. 一般截圖

1. 在主視窗選擇「矩形截圖」、「全螢幕」或「工作區」。
2. 矩形截圖請拖曳框選範圍；全螢幕與工作區則依螢幕選單選取目標螢幕。
3. 截圖完成後會開啟編輯工具列，可標註、複製或存檔。
4. 一般截圖流程可按 `Esc` 取消。

### 2. 長截圖

長截圖採「選取範圍後擷取」流程，適用於瀏覽器、文件檢視器與其他具有可捲動內容的應用程式。

1. 先在目標視窗中框選**同一個可捲動內容區**。
2. 框選時不要包含：瀏覽器分頁列、網址列或工具列、捲軸、固定側欄、浮動輸入框、懸浮按鈕或固定通知。
3. 若畫面有多個捲動區域，只選主要內容區，不要把外層頁面與內層面板混在同一個範圍。
4. 按「開始長截圖」。開始後不要移動滑鼠，也不要操作其他視窗。
5. 程式會依畫面變化進行連續擷取、對齊與拼接；完成後可在編輯工具列繼續處理。
6. 若要中止，請將滑鼠移開選取區域。程式會停止後保留目前已擷取的畫面。

長截圖是跨應用程式的影像擷取與拼接，並非所有程式都提供可直接讀取的完整頁面資料。內容動態更新、圖片延遲載入、固定浮動元件、捲動區域不明確、捲動速度過快，或目標程式阻擋系統擷取，都可能影響結果。建議先以短範圍測試，再進行完整擷取。

### 3. 螢幕錄影

1. 選擇「螢幕錄影」。
2. 框選要錄製的區域；框選只決定錄影範圍，不會鎖住該區域，錄影期間仍可操作其他應用程式。
3. 在浮動錄影控制列選擇 FPS、麥克風與系統聲音。
4. 按「開始錄影」。開始後浮動控制列會顯示錄影狀態與經過時間。
5. 按「停止並存檔」完成 MP4 存檔。

macOS 首次使用錄影與音訊功能時，請在「系統設定 → 隱私權與安全性」確認螢幕錄製、麥克風與必要的輔助使用權限。若未授權，可能無法擷取畫面或錄製音訊。

### 4. 開啟舊檔與編輯

1. 在功能列最左側按「開啟舊檔」。
2. 選擇 PNG、JPG 或 JPEG 圖片。
3. 使用編輯工具列進行裁切、擴增空白或新增標註。
4. 文字標註在輸入完成前可編輯；選取文字工具後點擊圖片，再輸入內容。
5. 編輯完成後，在工具列選擇 PNG 或 JPG，按下載圖示另存新檔。

## 開發歷程

### 第一階段：專案建立

- 初始專案由 Antigravity IDE 協助建立與整理。
- 後續將產品名稱由 Antigravity Screenshot 調整為 **UniSnap**。
- 以 Tauri + React + TypeScript 建立桌面 UI，以 Rust 承擔螢幕擷取、錄影與檔案處理。

### 第二階段：截圖與編輯器

- 建立矩形、全螢幕與工作區截圖流程。
- 加入多螢幕選擇、DPI／縮放比例處理與螢幕座標轉換。
- 建立圖片標註工具列，支援繪圖、形狀、馬賽克、文字與顏色設定。
- 加入開啟舊檔、裁切、擴增畫布與 PNG/JPG 輸出。

### 第三階段：長截圖

- 針對 macOS 沒有跨應用程式通用長截圖 API 的限制，採用「選取內容區、模擬捲動、連續擷取、影像對齊與拼接」架構。
- 修正 Retina／DPI 導致的選取範圍與輸出尺寸不一致問題。
- 移除會造成瀏覽器切換分頁的合成滑鼠點擊，改以游標定位與擷取流程處理。
- 加入捲動後穩定取樣，降低頁面尚未完成繪製時造成的殘缺影像。
- 使用者操作流程改為先框選再開始，避免一點擊就誤觸發拼接或切換視窗。

### 第四階段：螢幕錄影

- 由早期的單純影格寫入，逐步改為 macOS ScreenCaptureKit 系統擷取流程。
- 統一 MP4 輸出與時間基準，修正影片時長與實際錄影時間不一致問題。
- 加入浮動開始／停止控制列，避免控制按鈕被錄進影片內容。
- 加入 FPS、麥克風與系統聲音選項，以及錄影完成後的檔案回報。
- 錄影區域以選取矩形為準，讓使用者能在錄影期間繼續操作電腦。

### 第五階段：介面與發行

- 加入 UniSnap 品牌名稱、日間／夜間模式、設定、使用說明與關於頁面。
- 版本維持 `V 1.0`，macOS 應用程式內部版本值為 `1.0.0`。
- 建立 Apple Silicon macOS `.app` 與 `.dmg` 封裝。
- 建立公開 GitHub 儲存庫供版本管理與後續維護。




## 權限與安全注意事項

- 螢幕錄製、麥克風與輔助使用權限由 macOS 系統管理。
- 請只對信任的應用程式授予必要權限。
- 錄影檔、截圖與剪貼簿內容可能包含敏感資訊，請自行確認儲存位置與分享範圍。
- GitHub 公開儲存庫只提交原始碼與必要設定，不提交 API Key、Token、個人錄影、截圖、建置輸出或本機快取。
- 目前提供的是未簽章／未公證的 macOS 測試封裝；首次開啟可能出現 macOS 安全性警告。

## 整理版架構

整理版維持 macOS 專案與 Windows 專案分離，並將原生程式依責任拆分：

- `capture*`：截圖命令、螢幕模式、輸出與控制視窗。
- `scroll_*`：長截圖目標判斷、捲動輸入、影格對齊、固定區域遮罩與拼接。
- `record*`：錄影工作階段、影格來源、裁切、H.264／MP4、音訊與完成收尾。
- `editor_*` 與 `pin_windows`：圖片編輯視窗及置頂圖片視窗狀態。
- `image_data` 與 `capture_output`：PNG／JPEG／Data URL 等影像輸出共用邏輯。

入口檔只負責 Tauri 狀態、快捷鍵、Tray 選單與 command registration；平台差異集中在 macOS ScreenCaptureKit、CoreGraphics 與音訊橋接模組。

## 整理版驗證

```bash
cargo test --manifest-path src-tauri/Cargo.toml --all-targets --no-default-features
cargo clippy --manifest-path src-tauri/Cargo.toml --lib --no-default-features -- -D warnings
npm run build
npm run tauri build
```

自動化測試可驗證影像編碼、錄影裁切、長截圖位移／拼接與 MP4 寫入；多螢幕選擇、動態頁面長截圖、文字拖曳及剪貼簿仍需在實際 macOS 桌面環境驗收。

## 目前範圍與後續方向

- 目前主要驗證與封裝平台為 macOS Apple Silicon。
- Windows 11 支援尚未完成，需另行處理 Windows 螢幕擷取、音訊、權限與封裝差異。
- 長截圖對動態內容、複合捲動區與固定浮動元件仍需依目標程式進行實際驗收。
- 多行文字標註的逐行繪製與行距處理仍可作為後續編輯器強化項目。
