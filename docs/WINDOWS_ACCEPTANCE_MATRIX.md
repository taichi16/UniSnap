# Windows 11 驗收矩陣

本文件是 UniSnap-Windows 進入實機驗收時的固定紀錄格式。編譯與單元測試通過不等於 Windows runtime 驗收完成；每筆結果都必須記錄 Windows 版本、GPU、螢幕配置、縮放比例、目標應用程式、輸出尺寸與錯誤訊息。

開始測試前，可在 Windows 專案根目錄執行 `powershell -ExecutionPolicy Bypass -File scripts/windows-preflight.ps1`，先產生 OS、GPU、音訊裝置與工具鏈的環境摘要，再執行本矩陣。腳本不會取代功能驗收。

## 測試環境

| 欄位 | 實際值 |
|---|---|
| Windows 版本 | 待填 |
| UniSnap-Windows 版本／commit | 待填 |
| GPU／驅動程式 | 待填 |
| 螢幕配置 | 待填 |
| Windows 顯示縮放 | 待填 |
| 測試日期 | 待填 |

## 功能驗收

| 編號 | 類別 | 情境 | 預期結果 | 狀態 |
|---|---|---|---|---|
| W-01 | 啟動 | 乾淨環境啟動主視窗 | 主視窗正常顯示，無 command permission 錯誤 | 待測 |
| W-02 | 螢幕 | 單螢幕 100% DPI 列舉與全螢幕截圖 | 螢幕尺寸、位置與輸出影像一致 | 待測 |
| W-03 | DPI | 單螢幕 150% DPI 區域截圖 | 選取範圍不偏移、不重複縮放 | 待測 |
| W-04 | 多螢幕 | 100%／150% 混合 DPI、含負座標 | 選取與輸出落在正確螢幕及位置 | 待測 |
| W-05 | 編輯 | 標註、文字、馬賽克、畫布擴增與輸出 | PNG／JPG 尺寸與內容正確 | 待測 |
| W-06 | 剪貼簿 | 複製影像後貼入其他 Windows 應用程式 | 可貼上正確影像，權限錯誤有明確訊息 | 待測 |
| W-07 | 長截圖 | Chrome／Edge 一般頁面 | 拼接連續、固定列／欄不重複 | 待測 |
| W-08 | 長截圖 | Word／PDF 檢視器 | 成功或明確回報不支援，不得假成功 | 待測 |
| W-09 | 工具列 | 選取區接近右側 viewport 邊界 | 工具列完整可見，不被裁切或遮蔽 | 待測 |
| W-10 | 錄影 | 畫面錄影 30 FPS，停止並播放 MP4 | 檔案可播放、時長合理、影格數大於零 | 待測 |
| W-11 | 麥克風 | 啟用麥克風錄影 | MP4 可播放且音訊軌可讀取 | 待測 |
| W-12 | 系統音訊 | 勾選系統聲音並播放測試音 | WASAPI loopback 可擷取預設輸出，與麥克風混音後 MP4 可播放；無輸出裝置或權限不足時明確失敗 | 待測 |
| W-13 | 取消 | 截圖、長截圖、錄影進行中按 Escape／停止 | 正常結束或取消，不殘留 session 與暫存檔 | 待測 |
| W-14 | 權限 | 無麥克風或螢幕擷取權限 | 顯示可理解錯誤，其他功能仍可使用 | 待測 |
| W-15 | 鎖定 | Windows 鎖定／解除後再操作 | 不崩潰；失敗時回傳可診斷錯誤 | 待測 |

## 發行前門檻

- W-01 至 W-06、W-09 至 W-14 必須完成並保留證據。
- W-07、W-08 必須分別記錄成功案例與失敗邊界，不得以單一瀏覽器結果推論所有應用程式。
- W-10、W-11 尚未完成前，不得宣稱 Windows 錄影功能已正式驗收。
- 未完成簽章、乾淨環境安裝／移除與 SmartScreen 評估前，不得稱為正式發行版。
