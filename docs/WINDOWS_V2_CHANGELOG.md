# UniSnap Windows V2.0 改版與修正紀錄

本文件記錄 `windows-support` 分支於 2026-09-01 完成的 Windows 11 相容性、錄影可靠性與編輯器修正。應用程式版本維持 V2.0（`2.0.0`）。

## 錄影架構

- Windows 螢幕錄影改用 Windows Graphics Capture／DXGI 擷取與 Windows Media Foundation H.264 編碼。
- 音訊改由 Windows WASAPI／CPAL 擷取，停止錄影後使用 Windows 內建 AAC 編碼器與 MP4 muxer 合併。
- 不再要求使用者安裝 FFmpeg，也不再隨應用程式攜帶 FFmpeg。
- 固定使用 Windows 內建軟體 H.264 編碼路徑，降低不同 Intel、NVIDIA、AMD 顯示驅動造成的崩潰風險。
- 錄影先輸出 `.partial.mp4`，完成封裝後才改為正式 MP4，避免把不完整檔案顯示為成功結果。
- Windows 編碼暫存改放 UniSnap 本機 AppData 快取區，不再直接使用可能被 OneDrive、網路磁碟或公司政策重新導向的存檔資料夾；開始錄影前會先驗證最終資料夾可寫入，並針對防毒軟體短暫占用加入重試。
- 新增 `recording → finalizing → completed／failed` 狀態管理，避免停止後仍在封裝時被誤判為存檔失敗或啟動下一段錄影。

## 麥克風與系統音訊

- 可列出並選擇麥克風，也可跟隨 Windows 預設麥克風。
- 錄影選取期間定期更新裝置清單，支援錄影前接入 USB、藍牙或其他外接麥克風。
- 外接裝置消失或設定失效時退回 Windows 預設裝置，避免誤選其他裝置。
- 支援單聲道、雙聲道及多聲道麥克風輸入，統一轉換為 44.1 kHz 雙聲道。
- 使用者要求錄製麥克風或系統音訊但初始化失敗時，停止開始錄影並顯示原因，不再靜默產生無聲影片。
- 修正先選取錄影區域、再播放影音內容時可能發生的聲音先行與影音不同步問題。

## 錄影操作與多螢幕

- 修正錄影啟動時出現命令提示字元或其他額外視窗的問題。
- 修正快捷鍵啟動錄影可能出現全白畫面或視窗跳離的問題。
- 改善高 DPI、多螢幕與負座標環境的螢幕選擇、區域座標換算及裁切。
- 錄影控制列在擷取期間排除於影片內容之外。
- 增加錄影工作階段互斥與錯誤復原，避免重複啟動、提前停止及背景封裝互相干擾。

## 截圖、長截圖與編輯器

- 修正矩形截圖可能包含 UniSnap 工具列的問題。
- 修正長截圖點擊後立即結束或錯誤返回的流程。
- 修正長圖使用馬賽克時產生黑色色塊的問題，並補上長畫布馬賽克測試。
- 修正開啟既有長圖後，OCR 結果視窗在深色模式下文字不可讀的問題。
- OCR 結果改為可選取、可捲動的文字輸出區，並固定結果視窗的可讀對比。
- 統一截圖與編輯器工作區的深色外觀，避免主視窗深淺色設定覆寫編輯器工具列及對話框。
- 修正置頂貼圖、長截圖及編輯器生命週期之間的狀態清理。
- 文字工具可搜尋並選用目前 Windows 已安裝的系統字型；字型清單由 DirectWrite 本機列舉，不會上傳字型檔或使用者資料。
- 內建常用字型作為讀取失敗時的安全備援，並保留既有圖片文字物件的字型設定。

## 程式碼整理

- 將錄影音訊、FPS、麥克風裝置與啟動狀態集中到 `useRecordingPreferences`，降低擷取視窗與錄影設定的耦合。
- 將畫布文字輸入層抽離為 `CanvasTextInput`，把定位與輸入生命週期從主擷取視窗分離。
- 將系統字型列舉、狀態管理、選擇介面與 CSS 字型轉義拆分為獨立模組。
- 新增字型功能靜態契約與 Windows DirectWrite 實機單元測試，防止後續重構誤刪命令、權限或介面整合。

## 設定與介面

- 改善多螢幕選擇按鈕，避免下拉選單難以操作。
- 更新「使用說明」與「關於 UniSnap」為應用程式內對話框，不再依賴本機網頁伺服器。
- 增加錄影開始、封裝、完成與失敗狀態提示。
- 全域快捷鍵改為序列化、交易式重新註冊；連續變更時不再清除所有快捷鍵，註冊失敗會恢復原設定，並忽略按鍵長按的重複事件。
- `Escape` 取消操作改為獨立固定快捷鍵，不受截圖與錄影快捷鍵重新設定影響。
- 修正「關閉視窗時常駐系統匣」只在啟動時生效的問題；設定現在立即生效，新安裝預設關閉主視窗即退出。
- 設定頁新增「完全結束 UniSnap」，提供不受系統匣設定影響的明確退出路徑。

## 驗證

- 前端 TypeScript 與 Vite 正式建置。
- Tauri 前後端 command 契約檢查。
- 系統字型功能契約檢查與 DirectWrite 實機列舉測試。
- 快捷鍵重註冊、回復與完整退出路徑的靜態契約檢查。
- 深色介面、OCR 與開啟舊檔編輯路徑的 UI 契約檢查。
- Rust 格式檢查與單元測試，包括錄影裁切、時間軸、MP4 封裝及音訊重取樣；另保留長畫布馬賽克測試頁。
- Windows V2.0 MSI 與 NSIS 安裝檔建置。

## 執行環境

- Windows 11 x64。
- 需要 Microsoft Edge WebView2 Runtime；一般 Windows 11 已內建或由系統維護。
- 錄影使用 Windows 內建媒體元件，不需要另外安裝 FFmpeg。
